chooseImage 选择图片
0.2.0 新增
H5 微信公众号 微信小程序 支付宝小程序 抖音小程序
是否支持？ ✔ ✔ ✔ ✔ ✔ 1.0.0 新增

使用 

uni.$uniQuery.chooseImage().then(res=> {
    // 获取成功
}).catch(err=>{
    // 获取失败
});

其中，res的数据格式如下： 

// 数组的条目就是图片地址
Array<string>

配置项

其中chooseImage()方法还支持传递参数，比如图片地址类型： 

uni.$uniQuery.chooseImage({
    type: "base64"
});

具体可配置项如下：

属性 说明 类型 是否必输？ 默认值 备注
type 图片地址类型 string 否 "default" 可选值："default"默认类型、"base64"使用Base64地址（仅H5、微信公众号、微信小程序支持）
v2.3.0新增

权限相关

微信公众号

需要在 jsApiList 补充如下方法列表： 

wx.config({
    jsApiList: ["chooseImage", "getLocalImgData"]
})
